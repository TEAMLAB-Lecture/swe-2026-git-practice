# 프로젝트 코드베이스 설명

이 프로젝트는 팀 소개 카드를 보여주는 정적 웹페이지입니다.

## 파일 설명
index.html은 웹페이지의 기본 뼈대와 화면을 구성하는 메인 파일이고, style.css를 통해 전체적인 디자인과 레이아웃을 잡아줍니다. 

가장 중요한 기능은 app.js가 담당하고 있습니다. data/teams.js 파일 안에 각 팀의 이름과 모토, 팀원 정보가 저장되어 있는데, app.js가 이 데이터를 읽어와서 화면에 팀 카드로 그려주는 역할을 합니다.

## 실행 방법
별도의 라이브러리 설치 과정은 필요 없습니다. index.html 파일을 웹 브라우저로 직접 열거나, VS Code의 Live Server 확장 프로그램을 이용해 바로 화면을 띄워볼 수 있습니다.
