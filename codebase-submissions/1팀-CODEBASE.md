# 코드베이스 정리

이 저장소는 팀과 팀원 소개를 카드로 보여 주는 정적 웹페이지입니다. 별도 설치나 빌드 과정 없이 브라우저에서 실행할 수 있습니다.

## 파일별 역할

- `index.html`: 제목, 검색창, 카드가 표시될 영역, 하단 정보 등 페이지의 기본 구조를 만듭니다. `data/teams.js`를 먼저 불러오고 `app.js`를 그다음 불러옵니다.
- `style.css`: 페이지의 색상, 글꼴, 카드 배치와 간격을 정합니다. 화면 너비에 따라 카드 열 수가 바뀝니다.
- `data/teams.js`: 예시 팀과 1~4팀의 이름, 모토, 팀원 정보를 `window.TEAMS`에 저장합니다. 각 팀은 배정받은 팀 블록만 수정합니다.
- `app.js`: `window.TEAMS`를 읽어 팀 카드를 화면에 그립니다. 검색어로 팀 이름, 모토, 팀원 이름과 GitHub ID를 걸러 보여 주고 표시 중인 팀·팀원 수를 갱신합니다.
- `README.md`: 실습 목표, 팀 등록 방법, PR 진행 순서와 제출 확인 목록을 안내합니다.
- `.github/pull_request_template.md`: PR을 만들 때 작성할 `무엇을 바꿨나`, `왜`, `확인 방법` 항목의 기본 양식입니다.

## 실행 및 확인 방법

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다. 패키지 설치나 서버 실행은 필요하지 않습니다. 1팀 카드에 이름과 모토가 표시되는지 확인하고, 검색창에 팀 이름이나 사람 이름을 입력하면 카드 목록이 바뀌는지 확인할 수 있습니다.
